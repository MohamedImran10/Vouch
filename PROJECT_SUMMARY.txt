                              USAGE EXAMPLES
==============================================================================

1. START BACKEND:
   $ cd backend
   $ source venv/bin/activate
   $ uvicorn app.main:app --reload

   Server: http://localhost:8000
   API Docs: http://localhost:8000/docs

2. RUN BACKEND TESTS:
   $ pytest tests/ -v

   Result: 24 passed (14 graph + 10 API)

3. START FLUTTER WEB:
   $ cd frontend
   $ flutter run -d chrome

   Opens: http://localhost:<random-port>

4. BUILD ANDROID APK:
   $ flutter build apk --release

   Output: build/app/outputs/flutter-apk/app-release.apk

5. API CURL EXAMPLES:

   # Health check
   $ curl http://localhost:8000/health

   # Search plumbers from Alice's network
   $ curl "http://localhost:8000/api/search?user_id=alice&category=plumber"

   # Get trust path
   $ curl "http://localhost:8000/api/trust-path?from_id=alice&to_id=bob_plumber"
